# STM32 六轴运动控制卡

基于 STM32F103RCT6 的 6 轴步进电机控制器，支持七段 S 形加减速、力矩前馈补偿、最高 40kHz 脉冲并行输出。

---

## 硬件规格

| 项目 | 参数 |
|------|------|
| 主控 | STM32F103RCT6 (Cortex-M3, 72MHz) |
| 驱动 | TMC2209 ×6 (STEP/DIR 模式) |
| 输入 | 8 路光耦隔离 (定时回报) |
| 输出 | 8 路 GPIO (指令控制) |
| 通讯 | USART3, 115200bps, 0xFF/0xFE 帧协议 |
| 电源 | 24V 输入，板载 PVD 掉电检测 |

### 引脚映射

| 轴 | 定时器 | PWM 通道 | 脉冲引脚 | 方向引脚 | 使能引脚 |
|:--:|:------:|:--------:|:--------:|:--------:|:--------:|
| 1 | TIM1 | CH1 | PA8 | PC9 | PA9 |
| 2 | TIM8 | CH2 | PC7 | PC6 | PC8 |
| 3 | TIM2 | CH3 | PB10 | PB2 | PB11 |
| 4 | TIM3 | CH3 | PB0 | PC5 | PB1 |
| 5 | TIM5 | CH4 | PA3 | PA2 | PA4 |
| 6 | TIM4 | CH2 | PB7 | PB6 | PB8 |

> 所有定时器预分频 72-1，计数频率 1MHz，PWM 占空比 50%~75%（力矩补偿时调整）。

## 通讯协议

### 帧格式

```
 FF  │  CMD  │  DATA[0..N]  │  FE
 ─────┼───────┼──────────────┼──────
 包头  │  指令  │   可变长数据   │  包尾
 1B   │  1B   │     N B      │  1B
```

- 波特率 **115200**，数据位 8，停止位 1，无校验
- 帧长可变，`CMD` 决定 `DATA` 段长度
- 接收超时或数据错乱后自动复位帧解析状态机

### 指令速查

| CMD | 功能 | 数据长度 | 说明 |
|:---:|------|:-------:|------|
| `01` | 电机控制 (梯形) | 5B | 兼容旧版协议 |
| `02` | 输出控制 | 1B | 8 路 GPIO 位掩码 |
| `03` | S 曲线电机控制 | 8B | 七段 Jerk 限制加减速 |
| `04` | 力矩补偿配置 | 5B | 设置速度-占空比标定点 |
| `05` | 力矩补偿开关 | 2B | 使能/禁用某轴补偿 |
| `10` | 读取电机状态 | 1B | 返回当前步数/速度/占空比 |

## 指令详解

### `01` — 电机控制（梯形加减速）

```
 FF │ 01 │ MOTOR │ MODE │ DIR │ STEPS_H │ STEPS_L │ FE
────┼────┼───────┼──────┼─────┼─────────┼─────────┼────
    │    │ 1~6   │ 1/2/3│ 0/1 │  高8位   │  低8位   │
```

| 字段 | 值 | 含义 |
|------|:---|------|
| MODE | `01` | 恒速 — `STEPS` 字段表示速度 (Hz) |
| | `02` | 定步 — `STEPS` 字段表示步数 |
| | `03` | 停止 — 立即停转并关闭 PWM |
| DIR | `01` | 正转 |
| | `00` | 反转 |

> 梯形加减速固定参数：vstart=800, vmax=3200, acc=2400。如需自定义请使用 `03` 指令。

**示例** — 电机 1 定步正转 2000 步：
```
FF 01 01 02 01 07 D0 FE
```

---

### `02` — 输出控制

```
 FF │ 02 │ MASK │ FE
────┼────┼──────┼────
    │    │ bit0~7 │
```

`MASK` 为 8 位掩码，bit0 对应输出 1，低电平有效。

**示例** — 第 1、3 路输出低电平（其余高电平）：
```
MASK = 0000_0101 = 0x05
FF 02 05 FE
```

---

### `03` — S 曲线电机控制

七段 Jerk 限制加减速，短距离自动降级为 5 段或 3 段。

```
 FF │ 03 │ MOTOR │ MODE │ DIR │ STEPS_H │ STEPS_L │ V0_H │ V0_L │ JERK │ FE
────┼────┼───────┼──────┼─────┼─────────┼─────────┼──────┼──────┼──────┼────
    │    │ 1~6   │ 2/4  │ 0/1 │  高8位   │  低8位   │ 高8位 │ 低8位 │ ×100 │
```

| 字段 | 类型 | 说明 |
|------|:----|------|
| MODE | U8 | `04`=S 曲线, `02`=降级为梯形 |
| STEPS | U16 | 目标步数 (0~65535) |
| V0 | U16 | 起始速度 (steps/s) |
| JERK | U8 | 加加速度 = 值×100 (steps/s³) |

> S 曲线内部参数：a_max=2400 steps/s², v_max=3200 steps/s。

**示例** — 电机 1 S 曲线正转 2000 步，vstart=500，jerk=2000：
```
V0=500=0x01F4, JERK=2000/100=20=0x14
FF 03 01 04 01 07 D0 01 F4 14 FE
```

---

### `04` — 力矩补偿配置

高速段自动增大 PWM 占空比，补偿转矩衰减防止丢步。每轴 4 点线性插值。

```
 FF │ 04 │ AXIS │ INDEX │ DUTY │ SPD_H │ SPD_L │ FE
────┼────┼──────┼───────┼──────┼───────┼───────┼────
    │    │ 1~6  │ 0~3   │  %   │ 高8位  │ 低8位  │
```

| 字段 | 类型 | 范围 | 说明 |
|------|:----|:-----|------|
| INDEX | U8 | 0~3 | 标定点序号 |
| DUTY | U8 | 32~95 | 占空比 (%) |
| SPD | U16 | 0~65535 | 对应速度 (steps/s) |

**默认曲线**（上电复位后）：

| INDEX | 速度 | 占空比 |
|:-----:|:----:|:-----:|
| 0 | 0 | 50% |
| 1 | 800 | 55% |
| 2 | 3000 | 65% |
| 3 | 8000 | 75% |

**示例** — 电机 1 标定点 1：速度 1500 时占空比 60%：
```
SPD=1500=0x05DC, DUTY=60=0x3C
FF 04 01 01 3C 05 DC FE
```

---

### `05` — 力矩补偿开关

```
 FF │ 05 │ AXIS │ EN │ FE
────┼────┼──────┼────┼────
    │    │ 1~6  │0/1 │
```

`EN=01` 启用，`EN=00` 禁用。启用后按标定曲线自动调节占空比。

---

### `10` — 读取电机状态

```
发送:  FF │ 10 │ AXIS │ FE
返回:  AA │ AXIS │ MODE │ CUR_H │ CUR_L │ TGT_H │ TGT_L │ SPD_H │ SPD_L │ DUTY │ 55
```

| 字节 | 含义 |
|:---:|------|
| 1 | 包头 `AA` |
| 2 | 轴号 1~6 |
| 3 | 模式 (1=恒速/2=梯形/3=停止/4=S曲线) |
| 4-5 | 当前步数 U16 |
| 6-7 | 目标步数 U16 |
| 8-9 | 当前速度 U16 (steps/s) |
| 10 | 当前占空比 U8 (%) |
| 11 | 包尾 `55` |

---

## 输入回报（自动）

上电后每 100ms 自动发送一次 8 路输入状态：

```
 FF │ STATE │ FE
────┼───────┼────
    │ bit0~7 │
```

`STATE` 为 8 位，bit7~bit0 对应输入 8~1。`1`=高电平，`0`=低电平。回报频率可在 [Scheduler.c](Applications/Scheduler.c) 的 `Loop_10Hz` 中调整。

## 运动控制算法

### S 曲线加减速

采用七段 Jerk 限制速度曲线，消除梯形加减速在拐点处的加速度突变：

```
a_max  │     ┌──────┐
       │    /        \
       │   /          \
  0 ───┴──┴────────────┴──┴───→ t
       T1  T2  T3  T4  T5 T6 T7
```

| 段 | 加加速度 | 加速度变化 | 速度变化 |
|:--:|:------:|:----------:|:--------:|
| T1 | +J | 0→+a_max | 二次递增 |
| T2 | 0 | 恒定 +a_max | 线性递增 |
| T3 | −J | +a_max→0 | 二次递增 |
| T4 | 0 | 0 | **恒定 v_max** |
| T5 | −J | 0→−a_max | 二次递减 |
| T6 | 0 | 恒定 −a_max | 线性递减 |
| T7 | +J | −a_max→0 | 二次递减 |

**短距离降级策略**：距离不足以达到 a_max 时自动跳过 T2/T6（5 段）；不足以达到 v_max 时进一步跳过 T4（3 段三角形 S 曲线）。

### 定点数运算

STM32F103 无硬件 FPU，所有运动计算采用 **Q16.16 定点数**（int32_t，15 位整数 + 16 位小数）：

- 加减法：直接整数加减
- 乘法：`(a × b + 0x8000) >> 16`（int64 中间结果防溢出）
- 平方根：256 点查表 + 线性插值（~2μs）或 Newton 迭代（~15μs）
- 1/v 倒数：128 点查表 + 二分插值

ISR 热路径中**零浮点运算**，仅定点乘加 + 查表，执行时间从原来的 ~40μs（sqrtf）降至 ~3μs。

### 力矩前馈补偿

步进电机在高速段因反电动势增大导致绕组电流下降，转矩衰减易丢步。通过速度→占空比映射增大 PWM Duty，增加绕组能量供给：

```
Duty │
 75% │              ●━━━━━━━━━━━●
     │          ●━━━┘
 65% │      ●━━━┘
 55% │  ●━━━┘
 50% │━━┛
     └────┬──────┬──────┬──────→ speed
          800   3000   8000
```

补偿曲线可在线标定（`04` 指令），每轴独立配置。

## 开发指南

### 目录结构

```
├── Applications/    # 应用层：运动算法、调度器、指令解析
├── Hardware/        # 硬件层：电机驱动、串口、IO
├── Core/            # STM32 HAL 配置（CubeMX 生成）
├── Drivers/         # HAL 库 + CMSIS
└── MDK-ARM/         # EIDE 工程配置 + Keil 启动文件
```

### 二次开发

> **引脚更换只需改一处** — 在 CubeMX 中配置新引脚后，修改 [include.c](Applications/include.c) 中的 `en_ports[]`、`dir_port[]`、`motor_tim[]` 等映射数组即可。

**添加新指令** — 在 [control.c](Applications/control.c) 的 `Command_Control()` 中添加 `case` 分支，按协议格式解析数据包。

**调整调度频率** — 修改 [Scheduler.c](Applications/Scheduler.c) 的 `sched_tasks[]` 表，添加/删除/调整任务函数和频率。

### 构建

- IDE: VSCode + EIDE 插件
- 编译器: ARM Compiler 5 (AC5)
- 优化: `-O3`, `--one-elf-section-per-function`
- 烧录: OpenOCD (cmsis-dap) 或 ST-Link
